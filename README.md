# 🏋️ AI Fitness Tracker

An AI-powered fitness tracking system that uses machine learning to recognize exercises from sensor data, estimate repetitions, and visualize workout performance through an interactive 3D dashboard.

## 🚀 Features

- Exercise recognition using Machine Learning
- Random Forest model training and evaluation
- Sensor data preprocessing and feature engineering
- Outlier detection and removal
- Repetition estimation
- Exercise distribution analysis
- Flask-based dashboard
- Interactive 3D-inspired UI
- Model performance visualization
- Participant-based model evaluation

## 🛠️ Tech Stack

Python • Pandas • NumPy • Scikit-learn • SciPy • Matplotlib • Flask • HTML • CSS • JavaScript
